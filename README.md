# Family Portfolio — Allocation Designer (Tool 1)

## Setup (one-time, ~5 min)

```bash
cd family-portfolio
python -m venv .venv && source .venv/bin/activate    # or: .venv\Scripts\activate on Windows
pip install -r requirements.txt
```

## Workflow

### 1. Populate manual top-5 holdings (~30 min, one-time)

Open `data/holdings_top5_manual.csv` and fill in the top 5 holdings for these 4 ETFs:
- `world_hedged` → Invesco MSCI World EUR Hedged
- `world_equal_weight` → Invesco MSCI World Equal Weight
- `europe` → Amundi MSCI Europe
- `defense_global` → VanEck Defense
- `defense_europe` → WisdomTree Europe Defence

For each: copy security_name, weight_pct, sector, country from the issuer's product page.
Source URLs are in policy.yaml comments. Save the file.

### 2. Fetch data

```bash
python scripts/fetch_data.py
```

This pulls:
- 2y daily prices for all candidates with a yfinance ticker
- Top-5 holdings auto for iShares ETFs (commodities, em_ex_china, ai_infrastructure)
- Macro snapshot (EUR/USD, Brent, Gold, VIX)
- Merges manual + auto holdings into `data/holdings_top5.csv`

Re-run weekly (or whenever you want fresh data). Cached for 24h.

### 3. Launch the designer

```bash
streamlit run app.py
```

Opens at http://localhost:8501.

**Tabs:**
- **Designer** — sliders within allowed ranges. Live blended P/E, yield, vol, drawdown. Constraint check at top. Save scenarios with names.
- **Compare** — full metrics table for all 10 candidates.
- **Overlap** — pairwise shared holdings (catches Defense Global vs Defense Europe overlap, etc.).
- **Scenarios** — multi-select saved allocations to compare side-by-side.

### 4. Iterate with your dad

Open the designer, drag sliders, save 3-5 candidate allocations, compare them, pick one. Update `policy.yaml` with the locked weights (`weight_min = weight_max`), commit, done.

## What's NOT in this tool (intentional)

- No "optimal" weights / efficient frontier — judgment stays with you.
- No tax optimization yet — comes in Tool 2 (weekly tranche advisor).
- No portfolio tracking — comes after first tranche actually executes.

## Known issues / things to fix when you have time

- **yfinance tickers are placeholders** for some Italian-listed ETFs. If `metrics_snapshot.csv` shows blanks for `world_hedged`, `commodities`, etc., check Borsa Italiana for the correct `.MI` ticker and update `policy.yaml`.
- **iShares JSON shape varies** between funds. If holdings come back empty for the 3 iShares ETFs, the script logs a warning — fall back to manual paste for those.
- **No P/E for thematic ETFs** sometimes — yfinance `.info` doesn't always populate it for newer UCITS funds. Acceptable; the designer shows "n/a" and excludes them from weighted P/E.
